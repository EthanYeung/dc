# Build

Build only what is necessary for the next evidence gate or for reliable delivery of already validated value.

Before coding:
- link the build to a hypothesis or paying-customer obligation;
- define acceptance test;
- define maximum build time/cost;
- identify existing services that are cheaper than custom code.

After coding:
- run tests;
- verify the deployed behavior externally;
- record operating cost and new reusable assets;
- provide rollback instructions.
