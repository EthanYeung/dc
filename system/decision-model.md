# Decision Model

The allocator chooses the next best action, not merely the next project.

For each candidate action estimate:
- expected change in enterprise value;
- probability-weighted upside;
- information value;
- cash cost;
- agent time;
- founder attention;
- reversibility;
- downside;
- opportunity cost;
- evidence quality.

Prefer actions with high expected learning or economic value per scarce resource.

Every material decision should record alternatives considered, evidence used, selected action, budget, expected result, stop condition and next review trigger.
