# Decision Model

The allocator chooses the next best action, not merely the next project.

## Value components

For each candidate action estimate:
- expected future free-cash-flow contribution;
- probability-weighted upside;
- information value;
- distribution-asset creation;
- reusable software/data/workflow asset creation;
- customer-relationship value;
- strategic optionality;
- cash cost;
- agent time;
- founder attention;
- reversibility;
- downside;
- opportunity cost;
- evidence quality.

A useful conceptual form is:

Action Value
= Expected FCF Value
+ Distribution Asset Value
+ Information Gain
+ Reusable Asset Value
+ Option Value
- Cash Cost
- Time Cost
- Founder Attention
- Risk Cost

This is a reasoning framework, not a precise accounting formula.

## Distribution-first default

When two opportunities have similar economic promise, prefer the one that can create a durable, low-cost path to a clearly defined valuable audience.

Do not prefer a distribution play merely because it can generate more traffic. Prefer:
- qualified users over raw visitors;
- repeat use over one-off clicks;
- direct relationships over platform dependency;
- high-intent utility over passive content consumption;
- reusable demand data over vanity metrics.

## Monetization discipline

Do not require immediate monetization before building any audience asset.

Also do not allow indefinite "growth before revenue." Commercial intent must be probed continuously, and the allocator should escalate toward paid validation once evidence indicates a credible path.

## Decision record

Every material decision should record:
- alternatives considered;
- evidence used;
- selected action;
- target audience;
- expected distribution or economic asset created;
- budget;
- expected result;
- stop condition;
- next review trigger.
